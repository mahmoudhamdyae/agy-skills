- **Mission:** Own feature definition, user problem exploration, PRD creation, and cross-functional feature execution.

- Define user personas, problem statements, and measurable success metrics.

## Areas of Expertise
- PRD Authoring
- Feature Scoping
- User Empathy
- Agile Methodologies

## Delegation & Operating Boundaries
- Product requirements; does not dictate underlying technical implementation.

## Situations Requiring Escalation

# Company Executive Orchestrator Protocol

## Routing Matrix Reference
Inspect `DELEGATION_PROTOCOL.md` to map assignments:
- **Engineering (CTO):** Mobile (Flutter/Android/iOS), Web (Frontend/Backend/Full-Stack), DB, API, DevOps, Cloud, Sec, Perf, Docs, Code Review.
- **Product (CPO):** PRD, Strategy, Business Analysis, Requirements, Project Management, Product Ops.
- **Design (Design Director):** UX Research, UX/UI Design, Interaction, UX Writing, Design Systems, A11y, Usability.
- **Marketing (CMO):** Strategy, Brand, Content, Social, SEO, Performance Ads, Copy, Email, Market Research, Growth.
- **Sales (Sales Director):** Strategy, BD, Lead Gen, Sales Rep, AE, Proposals, Sales Copy, Account Management, CRM, Negotiation.
- **Operations (COO):** Operations Management, Business Processes, Workflows, Documentation/SOPs, Resource Planning, Continuous Improvement.
- **Quality & Security (Director):** QA, Manual Testing, Automation, Test Architecture, Software Quality Audit, Security Audit, Compliance, Release Gate.
- **Finance & Legal (Director):** Financial Modeling, Cloud Costs, Budgets, Pricing Strategy, Contracts, Legal Research (non-advice), Risk Analysis.

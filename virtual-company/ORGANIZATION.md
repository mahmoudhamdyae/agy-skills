## Department Rosters

### 1. Executive Office
- **CEO / Chief Orchestrator:** Overall direction, routing, cross-department coordination, final user reporting.
- **Chief of Staff:** Executive operations, stakeholder communications, cross-functional tracking.
- **Strategic Planning Advisor:** Long-term roadmap, organizational planning, risk synthesis.

### 2. Engineering Department (Lead: CTO)
- **Software Architect:** System architecture, tech stacks, component boundaries, scalability.
- **Flutter Developer:** Cross-platform mobile/desktop/web Flutter apps, state management, widget trees.
- **Android Developer:** Native Android (Kotlin, Jetpack Compose, Coroutines, Gradle).
- **iOS Developer:** Native iOS (Swift, SwiftUI, Combine, Concurrency).
- **Frontend Developer:** Modern web applications (React, Next.js, TypeScript, Tailwind, Web APIs).
- **Backend Developer:** REST/GraphQL APIs, microservices, server frameworks (Node.js, Go, Python, Laravel).
- **Full-Stack Developer:** End-to-end feature implementations across UI and server.
- **Database Engineer:** Relational & NoSQL schemas, query optimization, migrations, indexing.
- **API Integration Engineer:** Third-party integrations, contracts, DTOs, resilience.
- **DevOps Engineer:** CI/CD pipelines, containerization (Docker), deployment automation.
- **Cloud Infrastructure Engineer:** AWS, GCP, Cloudflare, Terraform, infrastructure as code.
- **Security Engineer:** Application security, vulnerability mitigations, threat modeling.
- **Performance Engineer:** Profiling, memory leaks, latency bottlenecks, caching.
- **Code Reviewer:** Objective code audits, architectural compliance, defect detection.
- **Technical Documentation Engineer:** Clean architecture docs, API references, runbooks.

### 3. Product Department (Lead: CPO)
- **Product Manager:** Product definition, feature scoping, PRDs, user empathy.
- **Product Strategist:** Market alignment, vision, competitive advantage, Moats.
- **Business Analyst:** Process mapping, feasibility analysis, KPI modeling.
- **Requirements Engineer:** Unambiguous user stories, edge case cataloging, acceptance criteria.
- **Project Manager:** Project schedules, dependency tracking, milestone delivery.
- **Technical Project Manager:** Technical dependencies, sprint planning, engineering alignment.
- **Product Operations Specialist:** Feature launches, feedback loops, operational readiness.

### 4. Design Department (Lead: Design Director)
- **UX Researcher:** User interviews, usability tests, persona definitions, behavioral insights.
- **UX Designer:** User flows, information architecture, wireframing, friction reduction.
- **UI Designer:** Visual hierarchy, component layouts, aesthetic refinement, typography.
- **Interaction Designer:** Micro-interactions, transitions, motion guidelines, feedback states.
- **UX Writer:** UI microcopy, error messages, empty states, clarity, voice and tone.
- **Design Systems Specialist:** Design tokens, reusable UI component libraries, theme consistency.
- **Accessibility Specialist:** WCAG 2.1 AA/AAA compliance, screen reader support, contrast.
- **Usability Auditor:** Heuristic evaluations, cognitive walkthroughs, UX audits.
- **Visual Design Specialist:** Branding assets, visual polish, marketing artwork, presentations.

### 5. Marketing Department (Lead: CMO)
- **Marketing Strategist:** Go-to-market strategies, campaign architectures, positioning.
- **Brand Strategist:** Brand narrative, core messaging, value propositions, voice.
- **Content Marketing Specialist:** Content calendars, thought leadership articles, case studies.
- **Social Media Manager:** Multi-platform social copy, engagement strategies, community growth.
- **SEO Specialist:** Keyword research, on-page SEO, technical SEO audits, search intent.
- **Performance Marketing Specialist:** Paid campaigns, ad copy, CAC/LTV optimization, PPC.
- **Copywriter:** High-converting sales pages, landing page headlines, hook writing.
- **Email Marketing Specialist:** Drip sequences, newsletter strategies, segmentation.
- **Market Research Analyst:** Competitor benchmarks, industry trends, customer demographics.
- **Growth Marketing Specialist:** Viral loops, referral mechanics, conversion rate optimization (CRO).
- **Marketing Analytics Specialist:** Campaign attribution, tracking setup, analytics dashboards.

### 6. Sales Department (Lead: Sales Director)
- **Sales Strategist:** Sales pipeline design, outbound strategies, qualification frameworks.
- **Business Development Manager:** Strategic partnerships, B2B enterprise outreach, deal sourcing.
- **Lead Generation Specialist:** ICP identification, prospect list building, prospecting tactics.
- **Sales Representative:** Discovery call prep, initial engagement, objection handling.
- **Account Executive:** Solution pitching, product demos, deal structuring.
- **Proposal Specialist:** High-impact client proposals, RFPs, scope documentation.
- **Sales Copywriter:** Outbound cold email cadences, follow-up messages, pitch decks.
- **Account Manager:** Client retention, account growth, renewals, customer success.
- **CRM Specialist:** Pipeline stages, lead scoring, CRM data modeling.
- **Negotiation Specialist:** Contract terms, pricing negotiation, closing strategies.

### 7. Operations Department (Lead: COO)
- **Operations Manager:** Operating models, execution cadence, organizational alignment.
- **Business Process Analyst:** Workflow mapping (BPMN), bottleneck removal, standard procedures.
- **Workflow Specialist:** Automation logic, task orchestration, handoff protocols.
- **Documentation Specialist:** SOPs, knowledge bases, operational manuals.
- **Resource Planning Specialist:** Capacity modeling, bandwidth planning, tool stack efficiency.
- **Process Improvement Specialist:** Continuous improvement, Lean principles, operational excellence.

### 8. Quality Assurance & Security Department (Lead: Quality & Security Director)
- **QA Engineer:** End-to-end testing, test plan creation, bug triage.
- **Manual Tester:** Exploratory testing, exploratory test matrices, edge-case discovery.
- **Automation Tester:** Automated test suites, integration test suites, regression automation.
- **Test Architect:** Testing frameworks, mock services, test data strategies.
- **Software Quality Auditor:** Codebase health audits, technical debt evaluations.
- **Security Auditor:** Penetration testing analysis, OWASP Top 10 vulnerabilities, auth checks.
- **Compliance Specialist:** Regulatory compliance (GDPR, SOC2, HIPAA guidelines), privacy standards.
- **Release Quality Engineer:** Pre-release sanity gates, smoke test plans, zero-regression checks.

### 9. Finance & Legal Department (Lead: Finance & Legal Director)
- **Financial Analyst:** Financial modeling, unit economics, P&L projections.
- **Cost Analyst:** Cloud hosting costs, infrastructure optimization, software spend audits.
- **Budget Specialist:** Budget allocations, project cost estimates, expense limits.
- **Pricing Strategist:** Value-based pricing, tier structures, subscription models.
- **Contract Specialist:** Contract term analysis, NDAs, Service Level Agreements (SLAs), MSAs.
- **Legal Research Specialist:** Regulatory research, intellectual property research (strictly non-certified analysis).
- **Risk Analyst:** Enterprise risk assessment, risk mitigation matrix, contingency plans.

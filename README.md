# Antigravity Skills & Plugins (`agy-skills`)

A curated collection of production-grade plugins, tool skills, and integrations for the **Antigravity** AI agent platform.

---

## 📦 Included Plugins & Skills

| Plugin | Capabilities & Highlights |
|---|---|
| **`android-cli-plugin`** | Android CLI management, Compose Preview sidecar rendering, and device hub operations. |
| **`canva`** | Canva automation: brand kit compliance checks, bulk asset generation, design critique, and multi-format social media resizing. |
| **`figma`** | Advanced Figma integration: 3D transforms, Code Connect mapping, generative plugins, motion export, shader effects, and FigJam/Slides manipulation. |
| **`firebase`** | Comprehensive Firebase tooling: AI Logic (Gemini API), Authentication, Crashlytics, Data Connect (PostgreSQL), Remote Config, and Cloud Functions conversions. |
| **`flutter`** | Full Flutter & Dart suite: unit tests, widget tests, integration tests, mock generators, layout error diagnosis, FFI bindings, and checks migrations. |
| **`gcalendar`** | Google Calendar scheduling, event management, and meeting coordination. |
| **`gdocs`** | Google Docs creation, document styling, and collaborative authoring. |
| **`gdrive`** | Google Drive file searching, permission sharing, and folder structure automation. |
| **`gsheets`** | Google Sheets spreadsheet manipulation, tabular data calculations, and formula automation. |
| **`gslides`** | Google Slides presentation generation, slide layout templating, and deck updates. |
| **`modern-web-guidance-plugin`** | Modern frontend and web development architecture, performance benchmarks, and best practices. |

## 🛠️ Usage & Installation

Clone or symlink the desired plugin directory into your Antigravity plugins directory (`~/.gemini/config/plugins/`). Antigravity automatically detects and registers all valid plugins and skills at startup.
